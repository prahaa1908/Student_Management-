# Student Attendance Management System

## Introduction

The Student Attendance Management System is a web-based application designed to help colleges manage student attendance efficiently.

It allows teachers to maintain attendance records, monitor attendance percentages, and generate attendance reports.

## Objectives

- Maintain student attendance records
- Allow teachers to mark attendance
- Calculate attendance percentage
- Identify students with low attendance
- Generate attendance reports

## Features

- Student registration
- Teacher login
- Mark daily attendance
- Edit attendance records
- View attendance percentage
- Generate attendance reports
- Low attendance warning

- Laptop or desktop computer

## Installation

1. Download or clone the project.
2. Open the project folder.
3. Open the project files using VS Code.
4. Open `index.html` in a web browser.

## Usage

1. Login to the system.
2. Select the required class.
3. Select the student.
4. Mark the student as Present or Absent.
5. Save the attendance.
6. View the attendance percentage.
7. Generate the attendance report.

## Attendance Calculation

Attendance percentage can be calculated using:

Attendance Percentage = (Number of Days Present / Total Working Days) × 100

## Example

If a student is present for 40 days out of 50 working days:

Attendance Percentage = (40 / 50) × 100

Attendance Percentage = 80%
